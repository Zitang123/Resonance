# Spotify attribution assets

Unmodified full white RGB logo files from Spotify's official 2024 logo bundle:
https://developer.spotify.com/images/guidelines/design/2024-spotify-full-logo.zip

Downloaded 7 September 2026. Used only to attribute Spotify playback, with a link back to the service. Spotify retains its trademarks. Follow https://developer.spotify.com/documentation/design when changing their display. The website uses the SVG on a dark background; Discord receives the PNG as a compact full-logo thumbnail for its dark interface. Live playback delivery included the attribution image; visual appearance across client themes remains unverified.
